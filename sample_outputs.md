# Sample Inputs and Outputs

This document demonstrates the Prompt Optimiser Agent using two example prompts.

## Test Case 1: Machine Learning

**Original Prompt**

> Explain machine learning.

**Optimized Prompt**

Explain the concept of machine learning clearly and comprehensively for a general audience. Provide a structured explanation that defines what machine learning is, how it works at a high level, and includes common real-world examples to aid understanding. Keep the explanation accessible without overly technical jargon.

**Observations**

The optimized prompt adds a clear explanation goal, specifies the intended audience, requests a structured response, and asks for real-world examples while limiting unnecessary technical jargon.

## Test Case 2: Study Tips

**Original Prompt**

> Give me tips for studying effectively.

**Additional Requirements**

- Target audience: First-year college students.
- Purpose: Prepare for upcoming exams.
- Include active recall and spaced repetition.
- Use clear headings and numbered points.
- Include an example daily study schedule.
- Use beginner-friendly language.
- Keep the advice realistic and practical.

**Optimized Prompt**

Act as an expert academic coach.

Provide a practical, beginner-friendly guide with realistic study tips for first-year college students preparing for upcoming exams.

Your response must:

- Use clear headings and numbered points.
- Explain evidence-based study techniques—specifically active recall and spaced repetition—in simple, easy-to-understand language.
- Include a simple, realistic example of a daily study schedule.
- Keep all advice actionable and easy to follow for someone new to college-level exams.

**Observations**

The optimized prompt establishes a clear role, identifies the target audience and purpose, and organizes the requested study techniques, answer format, and daily schedule into explicit requirements.
